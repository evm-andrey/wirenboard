# SVG-панель термостатов dashboard4

Светлые карточки пяти существующих Moes BHT-002, оформленные в стиле панели света.
`dashboard.svg` — рисунок, `bindings.json` — штатные SVG-привязки Web UI,
`panel.json` — полная конфигурация только dashboard4. `build.py` генерирует рисунок
и привязки; после генерации при сборке панели заменить svg.current и svg.params.
`layout.js` отвечает за адаптивную раскладку 1/2/3 колонки и клавиатурную активацию
штатных SVG-кнопок; MQTT подключения и публикации в нём отсутствуют.

Температура читается из существующих WB_thermostat_*/local_temperature.
Подпись динамически читается из Thermostat_*/sensor: OU — выносной датчик пола,
IN — встроенный датчик воздуха, AL — воздух с ограничением по датчику пола.
При обследовании всех пяти устройств sensor=OU. Физическое размещение датчиков
не осматривалось. Обозначение local_temperature само по себе не означает воздух.

Уставка показывается из фактического канала; душевая использует отдельный
heating_setpoint_state и корректно отображает 19 °C, даже при UI диапазоне 20–30.
Пресеты 20..30 шаг 1 записываются в существующий current_heating_setpoint.
Два значения ON/OFF одинаковые — повторный клик не переключает на другую уставку.
Режим переключает system_mode (heat/off). Нагрев и режим показаны отдельно:
включённый термостат может ожидать, не нагревая. При загрузке команды не посылаются.
Новые wb-rules не добавлялись, существующие сценарии и ограничения не менялись.

Установка: заменить только dashboard4 в актуальном /mnt/data/etc/wb-webui.conf.
Assets: /mnt/data/etc/wb-lighting-ui/thermostats.js и thermostats.css.
Добавить ссылки на них в существующий sub_filter nginx (образец в резервной папке),
проверить nginx -t, reload. Перед заменой сверить хеш актуального JSON.
Не заменять целиком конфигурацию устаревшим снимком.

Резервные копии и результаты: ../../thermostat-dashboard-20261003/.
Откат: вернуть только panel-before.json в актуальный список dashboards, убрать
две ссылки thermostats из nginx include с nginx -t/reload. Первоначальный include
сохранён как nginx-before.conf. Другие панели и правила при откате сохранить.

Проверки браузером 1600px и 390px: фактические значения всех пяти устройств,
отсутствие горизонтального переполнения, кнопки температуры/режима каждой комнаты,
клавиатура и сохранность панели света. Команды перехвачены до реальных устройств.
Физический тест нагрева и reboot не проводились.
