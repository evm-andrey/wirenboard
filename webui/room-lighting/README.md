# Свет по комнатам

Нативная панель Wiren Board `dashboard_lighting`, 11 комнат, 42 группы освещения,
5 штатных регуляторов яркости. Общая кнопка и 11 комнатных кнопок — разовые команды
выключения. Автоматизации продолжают работать. Вентиляция и вытяжка исключены.

Состав панели и виджетов: `new-panel.json`, `new-widgets.json`; соответствие комнат:
`ordered-rooms.json`. Сценарий: `../../wb-rules/apartment_lighting_master.js`.
Командные controls заканчиваются на `_cmd`, фактические статусы — `_state` и readonly.
Неизвестное состояние нагрузки показывается явно; при групповом выключении такой
канал пропускается с записью в журнал. При запуске сценарий команды свету не отправляет.

Оформление действует только на эту панель. CSS и JS размещены в
`/mnt/data/etc/wb-lighting-ui/`, nginx include —
`/etc/nginx/includes/default.wb.d/room-lighting-theme.conf`.
JS отвечает только за оформление статусов; управление выполняет штатный Web UI.
Перед перезагрузкой nginx выполнить `nginx -t`.
При обновлении Web UI проверить CSS на совместимость с изменившимися классами.
Отключение include возвращает штатное оформление без удаления виджетов и controls.

Резервные копии до и после установки, результаты проверок и скриншоты находятся в
`../../room-light-dashboard-20261003/`. Исходный сценарий — `master-before.js`,
исходная конфигурация интерфейса — `webui-before.json`.
Для полного отката удалить только добавленные панели/виджеты из актуальной
конфигурации, вернуть прежний defaultDashboardId и исходный сценарий,
удалить include, проверить nginx и выполнить reload. Полную исходную конфигурацию
восстанавливать лишь после сверки последующих пользовательских изменений.
Сохранённые retained метаданные добавленных controls при необходимости удалять
выборочно, сохраняя существующий `all_off_cmd`.

Проверено настоящим wb-rules на изолированном MQTT broker и в браузере при
1600px/390px с блокировкой команд на реальное оборудование. Физическое переключение
всех нагрузок в ходе этих проверок не проводилось.
